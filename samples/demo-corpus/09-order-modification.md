# Order Modification & Cancellation

## The key rule: before or after shipment?

Once your order ships, we cannot change it. The cutoff depends on processing time: orders placed Monday–Friday usually ship the same or next business day. **Contact us as soon as possible** and include your order number.

## Before the order ships

### Change shipping address

Free. Email us before shipment with the order number and the corrected address. Double-check the postal code — most failed deliveries come from a wrong postal code.

### Change item or size

We can swap items for a different size or color if the order hasn't shipped. If the new item has a different price, we charge or refund the difference.

### Cancel the order

We cancel it and refund in full to the original payment method. Refund takes 3–7 business days to appear.

## After the order has shipped

We cannot change the address, swap the item, or cancel. What we can do:

- Try to intercept the package with the carrier (not guaranteed).
- If the package returns to us as undeliverable, we refund the merchandise minus the original shipping cost.
- If you still want the item, you'll need to place a new order.

## I want to cancel but I've already received the item

Then it's a return, not a cancellation. See the Returns & Refunds policy — you have 30 days (US) or 14 days (UK/EU) from delivery to send it back.

## Rush orders

We don't offer a paid rush-processing option at this time. Choosing DHL Express at checkout speeds up **transit**, not processing.
